# Radar Chart Visualization (Primary Energy Breakdown)

This module generates radar charts (one per zone) showing the distribution of
primary energy consumption by category.

A second row of bar charts provides absolute values for each category.

Uses **Plotly** for rich interactivity.

---

## 📥 Input Format

Generated by the Manager:

Radar_Energy.xlsx


Structure:

| Zone | HVAC | DHW | Lighting | Equipment | ... |
|------|------|-----|----------|-----------|-----|

Values typically in **kWh/m²**.

---

## 📊 Output

Radar.html


Features:
- one radar chart per zone
- filled radar for active zone + outline for others
- bar chart below each radar
- hover with total energy
- publication-quality layout

---

## 🧩 Dependencies

- Plotly  
- Pandas  
- Colorcet
