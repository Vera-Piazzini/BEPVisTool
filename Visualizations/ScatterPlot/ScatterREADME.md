# Scatter Plot Visualization (ILAS Heating & Cooling vs Outddoor Temperature)

This module produces two scatter plots:
1. Heating rate vs outdoor temperature
2. Cooling rate vs outdoor temperature

Points are grouped by time of day (0–8, 8–19, 19–24), with regression lines for
each group and a global regression line.

Uses **Bokeh**.

---

## 📥 Input Format

Generated by the Manager:

Scatter_ILAS.xlsx


Required columns:

- `Outdoor_Temperature`
- `Zone_ILAS_HeatingRate`
- `Zone_ILAS_CoolingRate`
- `Date/Time` (HH:MM extracted for hour groups)

---

## 📊 Output

ScatterHeatingCooling.html


Features:
- three hour-based color clusters
- individual + global regression lines
- hover tools (°C, W/m²)
- interactive legend

---

## 🧩 Dependencies

- Bokeh  
- Pandas  
- Scipy  
- Numpy
